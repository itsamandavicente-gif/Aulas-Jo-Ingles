Como usar este painel
  1. Clique no quadrado à esquerda de cada missão para alternar o status: pendente → em andamento → concluído.
  2. Use o menu de status para pular direto para o estado desejado.
  3. O ícone de nota abre um campo para anotar dúvidas, revisão ou próximos passos.
  4. Os filtros e a busca ajudam a encontrar rapidamente o que falta.
  5. O progresso geral e por etapa é calculado automaticamente.
  6. Tudo é salvo neste navegador — reabra esta página para continuar de onde parou.
